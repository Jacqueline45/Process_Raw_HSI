# Process_Raw_HSI

This simple Python script does two things:
1. Processes Raw HSI
2. Processes Raw Binary Labeled Mask

Be sure to update all the file paths in the script!

## Datasets
Please visit this [link](https://zenodo.org/records/23174225). Datasets provided there have already been processed. This script may be useful to process your own HSI data.
